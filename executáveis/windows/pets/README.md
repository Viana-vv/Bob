# Bob

Esta versão inclui somente o Bob, com corpo preto, olhos e moldura brancos.

- `bryan.json`: configuração do Bob (nome, temperamento e brincadeiras).
- `bryan/`: frases, cartazes e memes do Bob.

O identificador interno `bryan` foi mantido para preservar a memória já salva.
Na interface, o personagem se chama Bob. Não há outros personagens nesta entrega.
